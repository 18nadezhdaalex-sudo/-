# Оргструктура страховой компании Life

Интерактивный дашборд по [PRD.md](PRD.md): целевая оргструктура life-страховщика в РК (до 400 сотрудников), базовый сценарий и сценарий автоматизации 30%.

## Как открыть

Откройте `index.html` двойным кликом — веб-сервер не нужен, всё работает офлайн.

## Структура

```
PRD.md                  требования — единственный источник данных
scripts/build-data.ps1  разбирает PRD.md и собирает данные
data/
  departments.json      подразделения (куратор, блок, база/авто, практика, правовая основа)
  positions.json        должности по подразделениям
  branches.json         филиальная сеть (20 точек)
  practices.json        лучшие практики (мир / Казахстан)
  requirements.json     требования законодательства и АРРФР
  data.js               бандл пяти JSON для открытия без сервера
index.html, css/, js/   дашборд
```

## Как обновить данные

1. Измените таблицы в `PRD.md` (разделы 5, 7, 8, 10, 11).
2. Пересоберите данные:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-data.ps1
```

Скрипт проверяет, что сумма должностей в каждом подразделении равна его численности, а сумма по филиалам — численности филиальной сети; при расхождении выдаёт предупреждение и код ошибки 1.

3. Обновите страницу в браузере. Все итоги (KPI, блоки, высвобожденные ставки, новые роли) считаются из данных автоматически.

## Разделы дашборда

- KPI: штат, головной офис, филиалы, высвобожденные ставки, новые цифровые роли, должности с согласованием АРРФР
- Органы управления и оргструктура по кураторам (клик по подразделению открывает его должности)
- Штат по функциональным блокам: база и автоматизация
- Таблица должностей с фильтрами: подразделение, поиск, «только изменения», «только регуляторные»
- Подразделения с лучшими практиками и правовой основой
- Филиальная сеть: график по ролям (база / авто) и таблица
- Лучшие практики с фильтром «мир / Казахстан»
- Требования законодательства и АРРФР
